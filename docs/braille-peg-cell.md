## What it is

A single braille cell — six dots — where each dot is a **button that pushes
through from either side**. Press a dot up, and it is raised. Press it from the
other side, and it drops flat.

That is the whole idea, and it is a good one. A learner can *set* a letter with
their fingers instead of only reading one that has been printed for them. Then
they can feel it, clear it, and set the next one.

## Why it matters for us

Everything else we hand a learner is fixed. A printed skull is always a skull. A
braille sheet always says the same thing. This is the first object we would put
in front of a learner that they can **change**, and that difference is worth
paying attention to:

- A blind learner can **write** as well as read — the loop closes.
- A sighted teacher who does not know braille can learn alongside the class,
  which is usually the real blocker in a mainstream school.
- It is cheap enough to print one per learner rather than one per classroom.
  Sharing a tactile object means most of the class waits.

## The braille cell, briefly

Six dots, two columns of three. They are **numbered**, and the numbering is what
everything else is built on:

```
   1  •  •  4
   2  •  •  5
   3  •  •  6
```

Left column top to bottom is 1, 2, 3. Right column top to bottom is 4, 5, 6.

The first ten letters use only the top four dots (1, 2, 4, 5):

| | | | | | | | | | |
|---|---|---|---|---|---|---|---|---|---|
| **a** | **b** | **c** | **d** | **e** | **f** | **g** | **h** | **i** | **j** |
| 1 | 1-2 | 1-4 | 1-4-5 | 1-5 | 1-2-4 | 1-2-4-5 | 1-2-5 | 2-4 | 2-4-5 |

Then the pattern repeats:

- **k to t** — the same shapes as **a to j**, plus **dot 3**.
- **u, v, x, y, z** — the same as **a, b, c, d, e**, plus **dots 3 and 6**.
- **w** is the odd one out: **2-4-5-6**. French braille had no *w*, so it was
  added later and does not fit the pattern. Learners always ask; this is the
  answer.

Two more worth knowing on day one:

- **Capital sign** — dot 6, placed before the letter.
- **Number sign** — dots 3-4-5-6, after which **a to j** mean **1 to 0**.

> Confirm with the partner school which braille code they teach. This is
> standard English braille, but the school's own practice is what the learner
> is being examined on, and they should be the authority — not this document.

## Printing

**Parts, per cell**

| Part | Quantity |
|---|---|
| Cell case | 1 |
| Spring | 6 — one per dot |
| Button cap | 12 — two per spring, one each side |

That is **19 pieces per cell**. Worth knowing before committing to a class set.

**Settings**

- **No supports needed** for any part.
- **The spring is the part that matters.** Print it with **enough perimeter
  lines that the flexible arms are solid** — if the arms come out with infill
  inside them, they will be weak and the button will not hold its position. This
  is the single most common way this print fails.
- **Tested in PLA and PETG.** PETG is the better choice for something being
  handled daily by a class; PLA is fine for a first trial.

**Test one first.** Print **one spring and one button cap** and check they fit
the cell case properly before printing all nineteen pieces, let alone thirty
sets of them. The designer says this explicitly and it is good advice.

---

## Assembly

Per dot, six times:

1. **Snap a button cap onto one side of the spring.**
2. **Insert the spring into the cell case.** It only fits one way round.
3. **Press the button all the way in**, so the spring pops through the case and
   is reachable from the other side.
4. **Snap the second button cap onto the spring** on that far side.

Repeat for all six positions. The cell is then finished — both faces have
buttons, and pressing from either side toggles that dot.

## Using it with a class

**Set, feel, clear, repeat.** The rhythm matters more than the content. A
learner who sets *a*, feels it, clears it and sets *b* has done more than one
who has had ten letters read at them.

**Teach the numbering before any letters.** Dots 1 to 6 as positions, drilled
until they are automatic. Every letter after that is just a list of numbers, and
a learner who knows the positions can be told a new letter over the phone.

**Use the a-to-j pattern openly.** Do not teach twenty-six unrelated shapes.
Teach ten, then "add dot 3", then "add dots 3 and 6". Learners who see the
system learn far faster than learners who memorise.

**Sighted learners should work with their eyes shut or the cell under the desk.**
Otherwise they read the dots visually, learn nothing about touch, and finish the
session believing braille is easier than it is.

**Give a blind learner the cell first and longest.** For them this is the lesson
itself, not an illustration of it.

**Record it.** The dashboard's session adaptations already include braille and
tactile materials as a fixed option. Recording that these were used is what
turns "we make tactile materials" into a number we can actually report.

## Related models by the same designer

Worth evaluating alongside this one — same author, so the same attribution
applies:

- [Braille Training Cell — 6MM](https://www.printables.com/model/807178-braille-training-cell-6mm)
- [Braille Training Cell — 4.5MM](https://www.thingiverse.com/thing:6538334) (Thingiverse)
- [Braille Sheet — 4.5MM](https://www.printables.com/model/1231140-braille-sheet-45mm)

The millimetre figures are dot spacing. **Standard braille is smaller than
either.** Oversized cells are easier for a beginner's fingers and for a sighted
teacher, but a learner has to reach standard spacing eventually — so decide
deliberately whether you are teaching braille or teaching *about* braille, and
ask the partner school which they want.

## Before the first visit

- [ ] Print one spring + one button cap and check the fit. Do not skip this.
- [ ] Print one complete cell and assemble it. Time yourself — 19 parts.
- [ ] Confirm the buttons hold position after fifty or so presses.
- [ ] Decide PLA or PETG for the class set.
- [ ] Agree dot spacing with the school.
- [ ] Work out cost and print time per cell, then per class.
- [ ] Note the attribution to 3D Printy wherever the object appears.
